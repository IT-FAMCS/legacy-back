# Профили, таски, отделы и енот

Согласовано пользователем 2026-11-28: «делай».
Расширяем существующие React/FastAPI механизмы. Саморедактирование личных полей всем должностям кроме участника; системные поля запрещены сервером. Фильтры выполненных, близких сроков (сегодня/завтра), просроченных и неназначенных тасок. Галочка пользователей без отделов, удаление отдела без удаления людей. Минимальная длительность загрузчика 1000 мс без задержки запросов. Сгенерированный анимированный енот с 10 фразами, отключение в профиле сохраняется в аккаунте. DOCX отчёт из карточки отдела: явный выбор отдела и мероприятия, все сотрудники, описание и сроки тасок, фактическое завершение из истории, предупреждения только по существующим правам. Архивация завершённых из текущей выборки атомарно с проверкой версий; восстановление с историей и прежним статусом. Изменённую app.db не трогать. Рабочие ветки feat/profile-tasks-raccoon; без push.

## Подход
Используем текущие API и UI, а генератор DOCX выделяем в отдельный модуль на стандартной библиотеке Python (OOXML ZIP), без новой зависимости. Маскот — сгенерированный спрайт и CSS-анимация, текстовые реплики без звука.
