# Согласия и сохранённые реквизиты

По указанию владельца применены настройки по умолчанию: имя и адрес оператора не отображаются; контакт — [аккаунт admin](https://famcs-legacy.by/user/admin); основные данные сайта хранятся в Республике Беларусь, доступ предоставляется авторизованным пользователям по их правам. Срок хранения не ограничен фиксированной календарной датой; сохраняются ограничения целями обработки, право на удаление и отзыв согласия. Данные о размещении предоставлены владельцем, инфраструктура независимо не проверялась.

Согласие работает без заполнения переменных окружения. Необязательные переопределения:

| Настройка | Значение |
| --- | --- |
| `PERSONAL_DATA_OPERATOR` | Имя/наименование оператора; по умолчанию не указано |
| `PERSONAL_DATA_ADDRESS` | Адрес оператора; по умолчанию не указан |
| `PERSONAL_DATA_CONTACT` | По умолчанию `https://famcs-legacy.by/user/admin` |
| `PERSONAL_DATA_PROCESSORS` | По умолчанию РБ, авторизованные пользователи согласно правам; Telegram описан отдельно |
| `PERSONAL_DATA_RETENTION` | По умолчанию без фиксированной даты, в пределах целей обработки и до удаления/отзыва согласно условиям |

Пустые значения используют эти настройки по умолчанию. Docker Compose передаёт необязательные переопределения из окружения. Отсутствие имени/наименования и адреса оператора не позволяет считать текст юридически полным: ссылка на аккаунт администратора не заменяет эти сведения. Заявление об отсутствии календарного ограничения не отменяет требований о необходимости хранения для заявленных целей и обработки обращений. Бот использует Telegram, поэтому РБ не объявляется единственным местом обработки всех сообщений.

Условия перечисляют ФИО и данные учёбы/контактов, служебные и Telegram-идентификаторы, задачи, комментарии и историю действий, оборудование, мероприятия, бюджетные заявки, чеки и реквизиты. Права и последствия дачи/отказа разъяснены отдельно. При входе в личный кабинет показывается явный флажок, а запись согласия хранит пользователя, дату, канал, полную копию условий и их версию. Изменение любого поля настроек либо текста условий требует нового согласия. Передача через Telegram описана в условиях; реальную схему трансграничной передачи должен проверить оператор.

Сохранение реквизитов требует отдельного добровольного согласия. Максимум 3 записи на пользователя, проверка лимита выполняется в сериализованной транзакции SQLite. Доступны только собственные записи. При отправке заявки реквизиты копируются в неё: удаление шаблона не изменяет платёжное поручение задним числом. Новые реквизиты заявки автоматически не сохраняются. Идентификаторы удалённых шаблонов повторно не используются.

Отзыв добровольного согласия удаляет все шаблоны. Отзыв основного согласия также отзывает добровольное, закрывает вход на сайт и запрещает новые заявки. Уже открытый профиль обновляет согласие каждые 15 секунд и при возврате в окно; сохранённые реквизиты после отзыва скрываются. Остальные исторические данные не удаляются автоматически: оператор обязан обработать обращение и определить законные основания и сроки хранения. Это техническая реализация согласий, а не подтверждение юридического соответствия всей обработки. Само наличие чекбокса не заменяет политику оператора, проверку оснований обработки и трансграничной передачи, организацию обработки обращений и удаления/резервного копирования по срокам.

Таблицы `personal_data_consents` и `saved_payout_details` создаются штатным `create_all`; существующие таблицы и данные бюджета не сбрасываются. Хранение шаблонов использует ту же SQLite БД, что и остальные данные проекта; в инфраструктуре должны быть ограничены доступ к БД и резервным копиям. CVV/CVC, PIN, одноразовые коды и пароли в реквизитах не запрашиваются.

## Проверка

- Backend: `venv/Scripts/python.exe -m unittest discover -s tests -q` (изолированные временные БД).
- Bot: `py -3.13 -m unittest discover -s tests -q` в `legacy-tg`.
- Site: `npm test`, `npm run build`, `npm run lint` в `legacy-frontend`.
- Браузер: запустить `tests/serve_budget_smoke.py` в backend; собрать frontend с `VITE_API_BASE_URL=http://127.0.0.1:4176`, затем `node --experimental-websocket tests/browser-budget-smoke.mjs`. В сценарии только вымышленные данные и временная БД.
